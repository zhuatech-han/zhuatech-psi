## 重现主要检查

```sh
cd backend
mvn -B spotless:check test package
cd ../frontend
npm ci --no-audit --no-fund
npm run format:check
npm run lint
npm test
npm run build
cd ..
docker compose --env-file /path/to/isolated-test.env config --quiet
docker compose --env-file /path/to/isolated-test.env -p psi-check up -d --build --wait
python3 scripts/smoke.py --url http://127.0.0.1:8096 --env-file /path/to/isolated-test.env --output /private/test-result.json
python3 scripts/release-check.py
git diff --check
```

冒烟脚本只针对明确指定的本地独立测试服务，创建虚构业务和临时仓管账号。输出包含该测试账号的随机密码，仅存于受限文件，不上传源码；运行完按部署手册清理自己的测试容器、数据卷和敏感结果。

## 验收边界

自动集成测试使用 H2 的 MySQL 兼容模式，另有真实 MySQL 8.4 部署验证。浏览器检查在 Chromium/Edge 内核的 1440×980 与 390×844 视口执行；不代表已验收所有浏览器和实体手机。打印验证包含打印样式及生成 PDF，不包含实体打印机。条码用模拟输入验证，未连接实体扫码枪。

未验收公网 HTTPS、实际银行/支付机构、税务发票、第三方平台或大规模压力负载；这些不属于本版功能。仅有 V1 迁移，未声称验证后续版本升级。业务范围、数据量上限和财务口径见 README。
